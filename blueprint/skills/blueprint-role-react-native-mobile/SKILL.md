# React-Native Mobile 开发

工作卡决定目标、交付和验收。角色 Prompt 记录三组外部 Skill 的安装方式和阶段职责。验证当前会话能读取所需 Skill，再用角色资源清单中的实际路径打开参考文档。

- **初稿** 用 Impeccable 的原生页面设计流程与资料 01–06 确定信息层级、导航、主要操作和交互状态。沿用应用现有设计系统，按场景判断 iOS 和 Android 的行为。
- **实现** 按现有 React Native 与 Expo 版本选择组件和 API。使用 Expo Skills 查证平台实现，使用 Vercel React Native Skills 核对列表、动画、图片和渲染性能。
- **审核** 对可运行的页面执行 `impeccable critique` 并逐项对照资源 07。修复与目标有关的发现，在受影响场景复查。交付可复现的设备、页面、条件和结果，标明未验证项。
